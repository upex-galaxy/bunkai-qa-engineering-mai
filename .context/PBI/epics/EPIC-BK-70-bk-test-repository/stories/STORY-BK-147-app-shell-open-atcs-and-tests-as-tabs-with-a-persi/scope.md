# BK-147 — Scope

> Jira field: `customfield_10119` · [View in Jira](https://jira.upexgalaxy.com/browse/BK-147)

- The project explorer tree stays visible on every project route, not only the workbench index.
- Opening an ATC or a Test opens it as a tab inside the workbench; several tabs can be open at once, switchable and closable.
- The project toolbar (New ATC, New Test, view switch, search) is reachable from any open tab.
- A direct link to an ATC or a Test opens it as a tab with the explorer visible.
- The item currently open is highlighted in the explorer.
